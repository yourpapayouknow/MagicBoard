# Third-party input resources

MagicBoard bundles LibrimeKit/librime and official Rime input resources.

- LibrimeKit and librime: BSD 3-Clause.
- Rime prelude, luna-pinyin, double-pinyin, essay, and stroke data: GPL-3.0.
- OpenCC conversion data: Apache-2.0.

The pinned source revisions and download procedure are recorded in
`scripts/vendor-rime-resources.zsh`. Resource license texts are included in
the `Licenses` directory; binary framework notices are provided by
LibrimeKit's `THIRD_PARTY_LICENSES.md`.
